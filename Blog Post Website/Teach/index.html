The Basic Language of the Web: HTML

Posted by Sooraj Prasad on Monday, August 7th 2023

All the mordernebsites and web applications are built using three fundaments technologies: HTML, CSS and JavaScript. These are the languages of the web.

In this post we will focus on HTML. We will learn what HTML is all about and why you should learn it.

What is HTML?

The HyperText Markup Language or HTML is the standard markup language for documents designed to be displayed in a web browser. It defines the meaning and structure of web content (not a programming language).

HTML consists of elements that describe different types of contents: paragraphs, links, headings, images, videos, etc. Web browsers understand HTML and render HTML code as websites.

In HTML, each elements is made up of 3 parts:

  1. The opening tag
  2. The closing tag
  3. The actual element

You can learn more at MDN Web Docs

Why to learn HTML?

There are countless reasons for learning the fundamentals language of the web. Here are few of them:

  • To be able to use the fundamental web dev language.
  • To built beautiful websites instead of relying on tools like Wordpress
  • To built web appliactions
  • To showcase your talent
  • To have fun😁
